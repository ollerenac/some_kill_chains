wargame catalog. The script is a derivative of `scripts/scrape_offen.py`, adapted to:
(a) attempt Spanish API content via `language=ES`, and
(b) translate all PDF structural labels (column headers, title, subtitle) to Spanish

Output file must not overwrite the existing `offen_wargame_catalog.pdf`.

Purpose: Provide a Spanish reference catalog for Spanish-speaking instructors and students.

</objective>
